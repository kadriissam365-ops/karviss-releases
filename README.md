# Karviss — versions pour macOS

**Karviss** est une application de dictée vocale pour le bureau : maintenez une touche, parlez, et le texte propre
apparaît là où vous écrivez. La transcription se fait **sur votre Mac** ; rien n'est envoyé en ligne, sauf si vous
choisissez vous-même un service d'IA en ligne dans les réglages.

Ce dépôt ne contient que les **versions installables**. Le code source est privé.

## Installer
1. Ouvrez la dernière version dans [Releases](https://github.com/kadriissam365-ops/karviss-releases/releases/latest).
2. Téléchargez `Karviss-<version>-arm64.dmg`, ouvrez-le et glissez **Karviss** dans **Applications**.
3. Au premier lancement, accordez les autorisations demandées (Accessibilité, Micro ; Agenda et son du système
   seulement si vous utilisez les réunions).

Configuration requise : Mac avec puce Apple (M1 ou plus récent), macOS 14 ou plus récent.

## Mises à jour
Karviss vérifie ce dépôt, télécharge les nouvelles versions en arrière-plan et vous propose de redémarrer pour les
installer (jamais pendant une dictée ou une réunion enregistrée). Réglages › Général › Mises à jour.

## Sécurité
Chaque version est signée « Developer ID Application : Issam KADRI (XY3HA7Y8HZ) » et **notarisée par Apple**.
Les mises à jour ne s'installent que si leur signature correspond.
